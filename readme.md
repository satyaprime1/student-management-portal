# 🎓 Student Management Portal

A Student Management Portal built using **Flask**, **SQLAlchemy**, **SQLite**, and **Bootstrap**. This project is being developed step-by-step as a backend and full-stack learning project.

## 🚀 Features

### ✅ Student Management
- Add Student
- View All Students
- Edit Student Details
- Delete Student

### 🔐 Authentication (In Progress)
- User Model
- Password Hashing
- Flask-Login Setup
- Login System
- Admin Account
- Route Protection (In Progress)

## 🛠️ Tech Stack

- Python
- Flask
- Flask-SQLAlchemy
- Flask-Login
- SQLite
- HTML
- Bootstrap 5

## ⚙️ Installation

Clone the repository

```bash
git clone https://github.com/YOUR_USERNAME/Student-Management-Portal.git
```

Go into the project

```bash
cd Student-Management-Portal
```

Install dependencies

```bash
pip install -r requirements.txt
```

Run the application

```bash
python app.py
```

Open your browser

```
http://127.0.0.1:5000
```
